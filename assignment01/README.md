# Assignment 1 — Single-Player Yatzy (HTML/CSS/JS)

## How to Run
Open `index.html` in your browser. No build tools required.

## Features
- Roll 5 dice; click dice to **hold**; roll up to **3 times** per turn.
- Click a score **category** to lock in a score (each used once).
- Scorecard updates and **Total** tallies automatically.
- **End Game** ends early or after all categories used.
- Responsive layout (mobile friendly).

## Files
- `index.html` – board UI (dice, buttons, scorecard)
- `styles.css` – responsive layout and styling
- `app.js` – game state, rolling, holding, scoring logic
